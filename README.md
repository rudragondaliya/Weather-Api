🌦 Worldwide Weather App Documentation
📌 Project Overview
The Worldwide Weather App allows users to input any city name and retrieve real-time weather data using the OpenWeatherMap API. It displays temperature (in Celsius), weather conditions, and the name of the city.

🔗 Live Preview
🌍 Try it here: https://weather-api-app-drab.vercel.app/

🧠 Features
Search weather by city name

Displays:

Temperature in °C

Weather description (e.g., clear sky, rain)

City name

Simple and attractive UI with gradient background

Icons powered by Bootstrap Icons

🛠 Technologies Used
HTML5

CSS3

JavaScript (ES6)

OpenWeatherMap API

Bootstrap Icons CDN

⚙️ How It Works
User enters a city name.

Submits the form.

The JavaScript fetches data from OpenWeatherMap API.

Displays the temperature, weather description, and city name dynamically.
